# Specialist Sources

This skill adapts workflow principles from the following MIT-licensed specialist skills. Prefer the installed specialist skill for deep work because its references and tooling evolve independently; use the integrated launch references to coordinate those specialties within a complete app lifecycle.

- [Swift Concurrency Agent Skill](https://github.com/AvdLee/Swift-Concurrency-Agent-Skill): settings-first isolation diagnosis, narrow migration, task lifetime, and cancellation verification.
- [SwiftUI Agent Skill](https://github.com/AvdLee/SwiftUI-Agent-Skill): state ownership, stable identity, source-first performance review, and Instruments routing.
- [Swift Testing Agent Skill](https://github.com/AvdLee/Swift-Testing-Agent-Skill): Swift Testing defaults, incremental XCTest coexistence, parameterization, traits, and parallel isolation.
- [Xcode Build Optimization Agent Skill](https://github.com/AvdLee/Xcode-Build-Optimization-Agent-Skill): wall-clock benchmarks, critical-path reasoning, recommendation/approval separation, and measured re-benchmarking.
- [Core Data Agent Skill](https://github.com/AvdLee/Core-Data-Agent-Skill): context confinement, object-ID handoff, persistent history, migration, and CloudKit production safeguards.

The coordination workflow, release evidence gates, XcodeGen authority rules, product-to-launch sequencing, and The Odds News lessons remain specific to `launch-native-ios-app`.
